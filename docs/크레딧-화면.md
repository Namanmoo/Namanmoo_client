# 크레딧 화면 — TODO

## 왜 필요한가

**법적 의무다.** 편의 기능이 아니다.

받아 쓰는 효과음이 CC BY 4.0이면 라이선스 3조 (a)(1)에 따라 저작자·제목·출처·라이선스를
**이용자가 볼 수 있는 곳**에 표기해야 한다. `Assets/Audio/LICENSES.md`는 리포지터리 안의
문서일 뿐이라 게임을 플레이하는 사람에게는 보이지 않는다. **이것만으로는 조건을 못 채운다.**

빌드된 게임 안에 표기가 있어야 배포가 적법해진다. 지금은 그게 없다.

## 무엇을 표시하는가

`Assets/Audio/LICENSES.md`의 "게임 화면에 넣을 문구" 절 내용을 그대로 띄운다.

```
사운드

"Water, Pouring, A.wav" by InspectorJ
  https://freesound.org/people/InspectorJ/sounds/421184/
  CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/) — 편집함
```

항목마다 이 다섯 가지가 빠지면 안 된다.

- 저작자 이름
- 원저작물 제목
- 출처 링크
- 라이선스 이름 **+ 전문 링크**
- 변경했다는 사실 (우리는 전부 노멀라이징을 거치므로 사실상 항상 해당)

## 어디에 붙이는가

Title 씬이 자연스럽다. `GameScenes.Title` → 버튼 하나로 크레딧을 열고 닫는 정도면 된다.
씬을 새로 만들 것 없이 Title 안의 패널로 충분하다.

WebGL이라 링크를 누를 수 있게 만들면 좋지만, 필수는 아니다. **텍스트로 URL이 보이기만 해도
조건은 충족된다.** 클릭 가능하게 하려면 `Application.OpenURL`을 쓴다.
