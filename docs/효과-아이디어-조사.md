# 효과 아이디어 조사 — 15개 게임의 무기 효과/시너지 메커니즘

> 카탈로그(`shared/effect-catalog.json`, 현재 효과 28종·트리거 5종·hitStyle 6종) 확장을 위한 조사 자료.
> 조사 대상: **액션 로그라이트**(Hades, Dead Cells, Enter the Gungeon, The Binding of Isaac, Noita) ·
> **생존형 로그라이크**(Vampire Survivors, Brotato, Halls of Torment, Risk of Rain 2, Tiny Rogues) ·
> **ARPG 접사 시스템**(Diablo 2/4, Path of Exile, Last Epoch, Terraria, Grim Dawn).
> 기존 28종과 겹치는 항목은 제외하고 선별했다. 비용은 현 버젯 스케일(무기 100pt, 기존 효과 baseCost 6~15 수준) 기준의 어림값.

## 2. 신규 트리거 후보

현재 5종: `on_hit` / `on_kill` / `after_seconds` / `on_cooldown` / `on_hp_below`.
조사에서 반복 등장한 확장 후보 (Grim Dawn의 proc 6종 체계가 사실상 표준 목록):

| 트리거 | 원작 | 비고 |
|---|---|---|
| **피격 시 (on_struck)** | D2, Grim Dawn, PoE (CwDT) | 최우선 후보. PoE 방식(횟수가 아닌 **누적 피해 임계치** 도달마다 발동)을 쓰면 다단히트에 폭주하지 않음. 발동 주도권이 없어 저비용 |
| **대시 시 (on_dash)** | D4 (Trickster) | 대시 자리에 함정·장판을 남김. 대시 쿨다운이 내장 쿨 역할 — 기존 `dash_charge` 효과와 시너지 |
| **적 행동 시 (on_enemy_act)** | Hades (Jolted) | 걸린 적이 다음 공격 동작을 할 때 격발. 광폭화 페이즈일수록 딜이 오르는 역설계 |
| **치명타 시 (on_crit)** | Grim Dawn | 치명타 시스템 도입 시 함께. 한방형 무기와 궁합 |
| **줍기 시 (on_pickup)** | Brotato (Baby Elephant) | 드랍 회수라는 비전투 행동이 트리거 — 회수 담당자에게 딜 보상 |
| **게이지 충전 시 (on_gauge_full)** | Hades (Call) | 피해를 주고받을수록 차는 자원형 트리거. 파티 동시 개방 연출 가능 |
| **투사체 소멸 시 (on_expire)** | Noita (Expiration Cast) | 빗나간 탄이 사거리 끝에서 2차 효과 발동 — "실패해도 보상" |
| **재장전/재사용 시 (on_reload)** | Gungeon | 재장전 개념 도입 시. 딜 공백을 능동적 타이밍 선택으로 전환 |

**공통 설계 원칙 (ARPG 조사 종합):** 발동확률 X%·내부 쿨다운 N초를 비용 산식의 **곱셈 계수**로 넣으면 강한 효과도 안전하게 편입 가능 (D2 chance-to-cast, D4 Lucky Hit, RoR2 proc coefficient). 발동 주도권이 낮은 트리거일수록(피격 > 방어 > 치명타) 저비용.

## 4. 조합 메커니즘 아이디어 (시스템 차원)

우선순위 순. ★는 우리 forge 컨셉과의 궁합 평가.

1. **트리거 캐스트 — 효과가 효과의 탄두가 된다** ★★★ (Noita)
   투사체 명중 지점에서 **다른 효과 슬롯을 실행**하도록 일반화하면, 28종 효과 전부가 서로의 payload가 될 수 있다 (화살 명중 → 그 자리에 번개 소환). 카탈로그가 28²으로 확장되는 가장 저렴한 방법. 타이머 캐스트(발사 N초 후 비행 중 격발)·만료 캐스트(소멸 시 격발)까지 같은 구조로 처리 가능.

2. **슬롯 순서 시스템 — 무기 = 프로그램** ★★★ (Noita 완드, Gungeon 획득 순서 의존 조합)
   수식어가 다음 슬롯에만 적용되고 좌→우로 읽히는 규칙. `[핑퐁][화상탄]`과 `[화상탄][핑퐁]`이 다른 무기가 된다. 대장간에서 슬롯 재배열만으로 무한한 커스텀 깊이 — **그림→무기 forge 컨셉과 궁합 최상**.

3. **2효과 융합 해금 (듀오)** ★★★ (Hades Duo Boons)
   파티가 서로 다른 두 계열을 보유하면 전용 융합 효과가 드랍/포지 풀에 등장 (화상+빙결 → "증기 폭발"). "네가 빙결 들었으니 내가 화상 들게" 식 빌드 회의를 자연 유발 — 협동 게임에 최적.

4. **밑칠→격발 2단 콤보** ★★☆ (Dead Cells Oil, VS 빙결 연계)
   자체 피해 없는 셋업 디버프 + 격발 속성의 명시적 2인 콤보. 지형 버전(기름 웅덩이를 팀원의 화염이 격발)도 가능 — 기존 장판과 달리 **협동 전용 지형**.

5. **네임드 변신 시너지 / 세트 변신** ★★☆ (Gungeon, Isaac Guppy, VS Evolution)
   특정 조합에 이름·비주얼·펀치라인 부여 ("시너지 발견!"), 또는 같은 계열 3종 수집 시 변신 (화상 3종 = 화염 정령). 수집 도감화로 반복 플레이 동기. LLM forge라면 시너지 명명을 AI가 즉석 생성하는 것도 가능.

6. **결속 UI — 트리거·효과 배정을 플레이어가 조합** ★★☆ (Grim Dawn Devotion)
   트리거-효과 쌍을 고정하지 않고 플레이어가 결속 UI로 직접 배정하면 같은 카탈로그로 조합 수가 곱으로 증가. 다단히트 무기엔 내부 쿨다운(ICD) 필수.

7. **곱연산 무배타 스택 + 역시너지 명시** ★☆☆ (Isaac, Tiny Rogues)
   전 효과 동시 적용 원칙(브림스톤+스푼벤더 = 휘는 레이저)이 실험 자체를 콘텐츠로 만든다. 단, 일부 조합은 의도적으로 충돌시키고 UI에 경고 — 배타 관계가 있어야 선택에 무게가 생김.

8. **파티 세트 보너스** ★★☆ (Brotato Weapon Classes 변형)
   파티원들이 같은 계열 효과를 들면 파티 보너스 발동 → 픽 단계 협의 유발. 장착 오라(D2 룬워드 — 파티 내 동일 오라 1개 제한, 4인이 서로 다른 오라 분담)와 묶어서 설계 가능.

## 5. 버젯 시스템 설계 시사점 (ARPG 조사 종합)

- **조건부 = 할인**: 무조건부 대비 조건 충족률(추정 uptime)에 비례해 비용 할인. 모든 조건부에 **표준 시간창(예: 4초)** 을 도입하면(PoE "Recently") 조건 종류를 늘려도 밸런스가 단순해짐.
- **페널티 = 환급**: 자해·받는 피해 증가·자원 전가는 마이너스 비용으로 버젯을 벌게 해줌. 단 협동에선 페널티가 힐러에게 전가되므로 환급률은 보수적으로.
- **확률·쿨다운 = 곱셈 계수**: `비용 × 발동확률 × (기준쿨/실쿨)` 산식으로 강한 효과를 안전하게 편입.
- **proc 폭주 제어**: 공속 빠른 무기의 트리거 남발은 무기별 proc 계수(`공속 × 계수 ≈ 상수`, D4 Lucky Hit / RoR2 방식)로 억제.
- **트레이드오프 접사(비용 0)** 카테고리: "+피해 -치명타" 같은 순수 사이드그레이드 (PoE Controlled Destruction, Terraria Ruthless). 소형 스탯 번들(Terraria Celestial)은 합계 대비 10~20% 할인.
- **성장형 무기**: 초기 비용은 낮고 런 중 성장분은 버젯 상한 초과 허용, 런 종료 시 리셋 (Last Epoch Weaver's Will, Tiny Rogues Attunement).
