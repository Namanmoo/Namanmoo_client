# DrawRaid 카탈로그 요약 (v1.0.0)

> 자동 생성 문서 — 원본은 `shared/effect-catalog.json` (단일 원본 원칙, 직접 수정 금지)

## 타격 방식 (hitStyles) — 무기 종류 6종

| id | 이름 | 설명 |
|---|---|---|
| `melee_swing` | 근접 휘두르기 | 무기를 호를 그리며 휘둘러 전방 부채꼴을 타격한다. |
| `melee_thrust` | 근접 찌르기 | 무기를 직선으로 내질러 좁고 긴 범위를 타격한다. |
| `projectile` | 투사체 발사 | 조준 방향으로 투사체를 발사한다. |
| `throw_return` | 투척 (회수) | 무기 자체를 던지고 되돌아오게 하여 회수한다. |
| `throw_consume` | 투척 (소모) | 무기 사본을 던져 소모한다. 연속 투척이 가능하다. |
| `deploy` | 설치 | 무기를 지면에 설치해 그 자리에서 효과를 발휘하게 한다. |

## 트리거 5종 — 효과가 발동하는 시점

| id | 이름 | 설명 |
|---|---|---|
| `on_hit` | 명중 시 | 무기 공격이 적에게 명중했을 때 발동한다. |
| `on_kill` | 처치 시 | 무기 공격으로 적을 처치했을 때 발동한다. |
| `after_seconds` | N초 후 | 공격(투척·설치 포함)이 이루어진 뒤 지정 시간이 지나면 발동한다. |
| `on_cooldown` | 재사용 대기 후 | 지정된 쿨다운이 돌 때마다 자동으로 발동한다. |
| `on_hp_below` | 체력 조건부 | 자신의 체력이 지정 비율 이하일 때 발동한다. |

| 이름 | 설명 | 기본 비용 |
|---|---|---|
| **체인 (연쇄)** (`chain`) | 명중한 피해가 주변 적에게 최대 N체까지 연쇄된다. | 10 |

| **도탄 (벽 반사)** (`ricochet`) | 투사체가 벽에 부딪히면 반사되어 계속 날아간다. | 7 |
| **분열** (`split`) | 명중 시 소투사체로 분열해 사방으로 퍼진다. | 10 |

### 범위 (6종)

| 이름 | 설명 | 기본 비용 |
|---|---|---|
| **폭발** (`explosion`) | 명중 지점에서 즉시 폭발해 범위 피해를 입힌다. | 12 |
| **지연 폭발** (`delayed_explosion`) | 일정 시간 뒤에 폭발한다. 지연이 길수록 위력이 커질 수 있다. | 10 |
| **화염 장판** (`zone_fire`) | 지면에 불타는 장판을 생성해 위에 있는 적에게 지속 피해를 준다. | 11 |
| **독 장판** (`zone_poison`) | 지면에 독 웅덩이를 생성해 위에 있는 적에게 독 중첩을 부여한다. | 11 |
| **감속 장판** (`zone_slow`) | 지면에 서리 장판을 생성해 위에 있는 적을 감속시킨다. | 9 |
| **충격파** (`shockwave`) | 발동 지점에서 원형 충격파가 퍼져 나가며 피해와 넉백을 준다. | 10 |

|---|---|---|
| **다중 발사** (`multishot`) | 투사체를 부채꼴 또는 일제 사격으로 여러 발 발사한다. | 12 |
| **유도** (`homing`) | 투사체가 가까운 적을 향해 휘어져 날아간다. | 11 |

| **파동 궤적** (`wave_trajectory`) | 투사체가 물결치는 궤적으로 날아가 넓은 폭을 훑는다. | 7 |
