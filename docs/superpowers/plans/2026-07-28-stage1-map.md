# Stage 1 Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate `Assets/Scenes/Stage1.unity` with a gray polygon stage, black collision boundary, and movable circular player.

**Architecture:** A focused runtime geometry class owns the stage outline and point-in-polygon behavior. An Editor-only builder converts that definition into a mesh, `LineRenderer`, closed `EdgeCollider2D`, circular player asset, camera, and saved Unity scene.

**Tech Stack:** Unity 6000.5.5f1, C#, URP 2D, Input System 1.19.0, Unity Test Framework 1.7.0

## Global Constraints

- Create `Assets/Scenes/Stage1.unity`.
- Preserve the reference image's upper room, lower room, and narrow central connector.
- Render the floor medium gray and the boundary black.
- Prevent the circular player from leaving the stage.
- Place the player safely in the lower room with `PlayerMovement`.
- Do not add decorations, enemies, animation, camera following, or scene transitions.

- [ ] **Step 1: Write failing tests**

Add tests proving that representative points in the lower room, connector, and upper room are inside, while points beyond the left and right outer walls are outside. Add a test proving every triangle index addresses an outline vertex.

Expected: compile failure because `Stage1MapDefinition` does not exist.

- [ ] **Step 3: Implement the polygon**

Define a clockwise concave outline of approximately 18 by 16 world units and a hand-authored triangle index array that covers both rooms and the connector. Implement ray-casting point containment.

- [ ] **Step 4: Run Edit Mode tests and verify GREEN**

Expected: all `Stage1MapDefinitionTests` pass.
