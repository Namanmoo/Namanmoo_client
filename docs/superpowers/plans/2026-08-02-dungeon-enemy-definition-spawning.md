# Dungeon EnemyDefinition Spawning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Dungeon normal rooms pass a serialized `EnemyDefinition` directly to `EnemyFactory` while preserving Stage 1 Krab and Dungeon boss behavior.

**Architecture:** `DungeonEncounter` continues to own room composition and deterministic spawn positions, but receives a normal-enemy definition instead of a raw Krab sprite. It builds `EnemySpawnRequest` values and calls `EnemyFactory.Create` directly. `DungeonSceneBuilder` creates and assigns the persistent Dungeon Krab definition asset; `KrabFactory` remains unchanged for Stage 1.

**Tech Stack:** Unity 6.0 (6000.5.5f1), C#, ScriptableObject assets, NUnit, Unity Test Framework

## Global Constraints

- Change only the Dungeon normal-enemy spawning path.
- Keep `Stage1KrabEncounterSetup -> KrabFactory -> EnemyFactory` unchanged.
- Keep Dungeon boss rooms on `BossFactory`.
- Preserve room-dependent counts, deterministic positions, `"Krab N"` instance names, and room-clear gates.
- Do not add floor tables, weighted selection, multiple normal definitions, or new behavior types.
- Follow red-green-refactor: no production change before its focused test has failed for the expected reason.
- Preserve unrelated user changes in the dirty worktree.

---

## File Structure

- `Assets/Scripts/Dungeon/DungeonEncounter.cs`: accept the normal definition and directly create normal enemies.
- `Assets/Tests/Editor/DungeonEncounterTests.cs`: prove definition-driven normal spawning independently of scene serialization.
- `Assets/Tests/PlayMode/DungeonBossPlayModeTests.cs`: adapt existing setup to the new `Configure` contract while preserving boss coverage.
- `Assets/Editor/DungeonSceneBuilder.cs`: create/update the persistent Dungeon Krab definition and assign it to the encounter.
- `Assets/Enemies/DungeonKrab.asset`: persistent definition generated by the scene builder.
- `Assets/Enemies/DungeonKrab.asset.meta`: Unity metadata generated with the asset.
- `Assets/Scenes/Dungeon.unity`: serialize the definition reference instead of `krabSprite`.
- `Assets/Tests/Editor/DungeonSceneBuilderTests.cs`: verify the asset values and serialized scene reference.
