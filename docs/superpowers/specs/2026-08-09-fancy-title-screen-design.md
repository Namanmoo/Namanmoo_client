# 상상 폭발형 타이틀 화면 디자인

## 목적

사용자가 제작한 `title.kra`의 구도와 이야기를 유지하면서, 색연필 낙서와 무기 상상 효과를 풍성하게 추가한 16:9 게임 타이틀 화면을 만든다. 화면을 처음 본 플레이어가 '그린 무기가 현실로 튀어나오는 게임'이라는 설정을 즉시 이해해야 한다.

## 기준 이미지

- 구성·이야기 기준: `C:/Users/dksco/OneDrive/Desktop/리소스/title.kra`
- 기존 타이틀 참고: `Assets/UI/Title.png`
- `title.kra`의 핵심인 왼쪽 제목과 메뉴, 오른쪽 캐릭터와 책상, 상단 말풍선, 오른쪽 나무 구도를 유지한다.

## 화면 규격

- 캔버스: 1920 x 1080px
- 화면비: 16:9
- 포맷: RGB/Alpha 8비트 PNG
- 색상 공간: sRGB
- 배경: 불투명한 밝은 공책 종이
- 최종 파일: `Assets/UI/Title_Fancy_01.png`
- 기존 `Assets/UI/Title.png`는 덮어쓰거나 수정하지 않는다.

## 전체 구도

### 왼쪽 55%

- 영어 제목을 두 줄로 배치한다.
  - 첫 줄: `MAKE YOUR`
  - 둘째 줄: `OWN WEAPON`
- `OWN WEAPON`을 첫 줄보다 약 20% 크게 만든다.
- 제목은 검은 손그림 외곽선과 색연필 채색을 사용한다.
- 왼쪽 아래에는 `Game Start` 버튼 하나만 배치한다.
- 버튼 주변에는 기능을 방해하지 않는 작은 별, 화살표와 연필선만 둔다.

### 오른쪽 45%

- 주인공은 책상 뒤에 앉아 커다란 파란색 펜을 오른손에 들고 무기를 그린다.
- 주인공의 특징은 커다란 둥근 흰 머리, 큰 검은 눈, 작은 W자형 입, 밀짚모자, 빨간 조끼와 파란 허리띠다.
- 캐릭터의 표정은 자신감 있고 신이 난 모습이어야 한다.
- 책상 위에는 종이, 색연필, 지우개와 실패한 무기 스케치 몇 장을 배치한다.
- 오른쪽 가장자리에는 굵은 갈색 줄기와 초록 색연필 잎을 가진 큰 나무를 둔다.

### 상상 폭발 효과

- 캐릭터가 그리는 종이에서 검, 도끼, 활, 마법봉과 장난감 같은 총이 낙서 형태로 튀어나온다.
- 무기들은 오른쪽 아래에서 화면 중앙 위쪽으로 휘어지는 흐름을 만든다.
- 무기 사이에는 별, 번개, 색연필 가루, 종잇조각과 짧은 충격선을 배치한다.
- 무기는 제목 글자와 `Game Start` 버튼을 가리지 않는다.
- 무기 형태는 서로 명확히 구분되지만 사실적인 금속이나 3D 렌더링으로 표현하지 않는다.

## 말풍선

- 캐릭터 머리 위쪽에 흰색 말풍선을 둔다.
- 문구는 정확히 `나 그림왕이 될 거야!`로 표기한다.
- 말풍선 꼬리는 캐릭터를 향해야 한다.
- 말풍선은 제목 영역을 침범하지 않는다.

## 배경

- 전체 바탕은 종이 결이 아주 약하게 보이는 따뜻한 흰색이다.
- 하늘은 연한 파랑 색연필을 성기게 칠해 흰 종이 틈이 보이게 한다.
- 아래쪽에는 밝은 초록 잔디와 작은 꽃, 멀리 있는 둥근 언덕을 배치한다.
- 배경 요소의 명도와 선 굵기는 제목과 캐릭터보다 약하게 한다.
- 화면 가장자리까지 장식은 이어지지만 중앙 정보 영역에는 충분한 여백을 남긴다.

## 그림체와 색상

- 매끈한 벡터선이 아닌 두께와 압력이 불규칙한 검은 손그림 선을 사용한다.
- 빨강, 파랑, 초록, 노랑을 핵심 색으로 사용하고 갈색과 옅은 하늘색을 보조로 사용한다.
- 색연필의 결, 겹쳐 칠한 선과 흰 종이 틈을 살린다.
- 유아용 상업 일러스트처럼 지나치게 매끈하거나 귀엽게 정제하지 않는다.
- 3D 입체 효과, 금속 광택, 사실적인 조명과 그림자, 정교한 판타지 문양을 사용하지 않는다.

## 글자 처리

- 생성 그림에는 제목, 말풍선 문구와 버튼 글자를 넣지 않고 각각의 안전 영역만 만든다.
- 최종 문구는 별도로 합성해 오탈자를 막는다.
- 제목은 대문자 `MAKE YOUR` / `OWN WEAPON`으로 표기한다.
- 버튼은 대소문자를 유지해 `Game Start`로 표기한다.
- 말풍선은 `나 그림왕이 될 거야!`로 표기한다.

## 검증 기준

- 결과 파일이 정확히 1920 x 1080px여야 한다.
- 제목, 말풍선과 버튼 문구에 오탈자가 없어야 한다.
- 화면을 축소해도 `OWN WEAPON`과 `Game Start`가 즉시 읽혀야 한다.
- 캐릭터, 책상과 큰 나무가 화면 오른쪽에 있어야 한다.
- 최소 네 종류의 무기 낙서가 종이에서 튀어나오는 흐름을 보여야 한다.
- 제목과 버튼 위에 무기나 장식이 겹치지 않아야 한다.
- 기존 `title.kra`의 구도를 알아볼 수 있어야 한다.
- 기존 Unity 타이틀 이미지와 씬은 수정하지 않는다.

## 제외 범위

- 이번 작업에서는 Unity 타이틀 씬에 이미지를 연결하지 않는다.
- 버튼 클릭 동작, 화면 전환과 애니메이션은 수정하지 않는다.
- `Game Start` 이외의 설정이나 종료 버튼을 추가하지 않는다.
