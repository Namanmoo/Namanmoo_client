# 타이틀 화면 순백색 보정 디자인

## 목적

`Assets/UI/Title_Fancy_01.png`의 종이 바탕에 남은 크림색과 누런 기운을 제거해 새하얀 스케치북 위에 색연필로 그린 인상으로 바꾼다.

## 입력과 결과

- 입력 장면: `tmp/imagegen/Title_Fancy_Scene_1920x1080.png`
- 현재 완성본 참고: `Assets/UI/Title_Fancy_01.png`
- 새 결과: `Assets/UI/Title_Fancy_02.png`
- 규격: 1920 x 1080px, RGB/Alpha 8비트 PNG, sRGB
- 기존 `Title_Fancy_01.png`와 `Assets/UI/Title.png`는 수정하거나 덮어쓰지 않는다.

## 수정 범위

- 종이 바탕의 베이지색, 크림색과 노란 색조를 제거한다.
- 빈 배경, 말풍선 내부, Game Start 버튼 바탕과 캐릭터의 흰 얼굴은 중성 순백색에 가깝게 만든다.
- 기본 종이색은 `#FFFFFF`를 목표로 한다.
- 종이 질감은 색이 없는 매우 옅은 중성 회색 결만 허용한다.
- 전체 화면에 노란 조명이나 세피아 필터가 느껴지지 않아야 한다.

## 반드시 보존할 요소

- 태양, 별, 밀짚모자, 마법봉과 무기의 의도적인 노란색 크레용
- 빨강, 파랑, 초록 크레용의 채도와 선 결
- 갈색 나무와 책상
- 캐릭터·무기·꽃·언덕·나무의 형태와 위치
- 제목 `MAKE YOUR` / `OWN WEAPON`
- 말풍선 `나 그림왕이 될 거야!`
- 단일 버튼 `Game Start`
- 모든 검은 외곽선과 현재 화면 구도

## 제작 방식

- 글자가 없는 장면을 정밀 색 보정한 뒤 정확한 문구를 다시 합성한다.
- 이미지 생성 편집에는 종이와 흰 영역의 색온도만 바꾸도록 지시한다.
- 크롭, 물체 추가·삭제, 선 재해석과 구성 변경은 허용하지 않는다.

## 검증 기준

- 결과가 정확히 1920 x 1080px여야 한다.
- 왼쪽 빈 종이 영역이 시각적으로 순백색이어야 한다.
- 흰 영역에 노란색 또는 갈색 색조가 남지 않아야 한다.
- 의도적인 노란 크레용 요소가 회색이나 흰색으로 탈색되지 않아야 한다.
- 네 문구가 정확하고 잘리지 않아야 한다.
- 기존 두 타이틀 PNG가 변경되지 않아야 한다.
