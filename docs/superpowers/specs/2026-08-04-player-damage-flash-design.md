# 플레이어 피격 점멸 설계

## 목표

몬스터의 공격으로 플레이어에게 실제 피해가 적용되면, 해당 공격이 부여한 무적시간 동안 플레이어 몸체가 검정색으로 점멸한다.

## 범위

- 플레이어 몸체의 `SpriteRenderer`만 점멸한다.
- 손에 든 무기와 UI에는 효과를 적용하지 않는다.
- 플레이어와 몬스터의 체력, 공격력, 이동 속도, 발사체 속도 및 기존 무적시간 값은 변경하지 않는다.
- 피해가 무적 또는 유효하지 않은 피해량 때문에 거부되면 점멸하지 않는다.

## 구조

### PlayerHealth

`TryTakeDamage`가 실제로 체력을 감소시키고 무적시간을 부여한 경우에만 피격 이벤트를 발생시킨다. 이벤트는 해당 피격에 적용된 무적 지속시간을 전달한다. 기존 체력 변경 및 사망 이벤트의 의미는 바꾸지 않는다.

### PlayerDamageFlash

플레이어 루트에 붙는 독립 컴포넌트로 다음 책임만 가진다.

- `PlayerHealth`의 피격 이벤트 구독 및 해제
- 플레이어 몸체 렌더러 참조 보관
- 피격 시 기존 점멸을 갱신하고 새 무적 지속시간 동안 점멸
- 약 0.1초 간격으로 원래 색상과 검정색 전환
- 효과 종료 또는 컴포넌트 비활성화 시 원래 색상 복구

점멸 도중 다시 유효한 피격이 발생하면 실행 중인 효과를 중복시키지 않고 최신 피격을 기준으로 다시 시작한다.

### PlayerFactory

플레이어를 생성할 때 `PlayerDamageFlash`를 추가하고 이미 생성한 몸체 `SpriteRenderer`와 `PlayerHealth`를 전달한다. 이 방식으로 자식 검색 중 무기 렌더러를 잘못 선택하지 않도록 한다.

## 동작 흐름

1. 몬스터 공격 코드가 기존처럼 `PlayerHealth.TryTakeDamage`를 호출한다.
2. 피해가 승인되면 체력이 감소하고 무적시간이 설정된다.
3. `PlayerHealth`가 피격 이벤트를 발생시킨다.
4. `PlayerDamageFlash`가 몸체 색상을 검정색과 원래 색상으로 반복 전환한다.
5. 무적 지속시간이 끝나면 몸체를 원래 색상으로 복구한다.

## 예외 처리

- 몸체 렌더러 또는 `PlayerHealth`가 없으면 점멸 컴포넌트는 효과를 실행하지 않는다.
- 무적 지속시간이 0이면 색상을 변경하지 않고 원래 색상을 유지한다.
- 비활성화나 파괴 중에도 렌더러가 존재하면 원래 색상을 복구한다.
- 치명적인 피해에서도 기존 사망 흐름을 변경하지 않는다.

## 테스트

테스트 우선으로 다음을 검증한다.

- 실제 피해가 적용되면 몸체가 검정색으로 점멸한다.
- 점멸 간격이 지나면 원래 색상과 검정색이 번갈아 나타난다.
- 무적 지속시간이 끝나면 원래 색상으로 복구된다.
- 무적 중 거부된 피해는 새 점멸을 시작하지 않는다.
- 팩토리가 점멸 컴포넌트를 몸체 렌더러에 정확히 연결한다.
