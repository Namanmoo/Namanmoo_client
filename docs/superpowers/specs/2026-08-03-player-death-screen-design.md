# 플레이어 사망 화면 설계

## 목표

플레이어 체력이 0이 되면 게임 진행과 조작을 즉시 멈추고 플레이어 캐릭터를
숨긴다. 화면을 1초 동안 검정색으로 페이드한 뒤 중앙에
`이번에도 틀렸나...` 문구와 `타이틀화면으로 돌아가기`,
`처음부터 다시하기` 버튼을 표시한다.

## 동작 흐름

1. `PlayerHealth`의 체력이 처음으로 0이 되는 순간 사망 이벤트를 한 번 발생시킨다.
2. 사망 화면 컨트롤러는 플레이어 오브젝트를 비활성화해 캐릭터와 조작을 제거한다.
3. `Time.timeScale`을 0으로 설정해 적, 투사체, 이동 등 게임 진행을 즉시 멈춘다.
4. UI 최상단의 검정 오버레이를 실시간 기준 1초 동안 불투명하게 페이드한다.
5. 페이드가 끝난 뒤 중앙 문구와 두 버튼을 활성화한다.
6. `타이틀화면으로 돌아가기`는 `GameScenes.Title`을 로드한다.
7. `처음부터 다시하기`는 현재 활성 스테이지 씬을 새로 로드한다.
8. 어느 버튼이든 씬을 로드하기 직전에 `Time.timeScale`을 1로 복원한다.

## 구조

### PlayerHealth

기존 체력 계산과 `HealthChanged` 이벤트는 유지한다. 별도의 `Died` 이벤트를
추가하며, 유효한 피해로 체력이 양수에서 0으로 바뀔 때 한 번만 발생시킨다.
이미 체력이 0인 상태의 추가 피해는 무시한다.

### PlayerDeathScreen

사망 상태와 화면 전환을 담당하는 `MonoBehaviour`다. `PlayerHealth.Died`를
구독하고 사망 시 플레이어 비활성화, 시간 정지, 페이드, 메뉴 표시를 순서대로
수행한다. 페이드는 `Time.timeScale`이 0이어도 진행되도록
`Time.unscaledDeltaTime`을 사용한다.

컴포넌트가 비활성화되거나 파괴될 때 이벤트 구독을 해제한다. 사망 처리는
중복 실행되지 않도록 내부 상태로 한 번만 시작한다.

### PlayerDeathScreenUIFactory

기존 런타임 UI 팩토리 패턴에 맞춰 Screen Space Overlay 캔버스를 생성한다.
캔버스는 1920×1080 기준 해상도와 화면 크기 대응 스케일러를 사용하며 다른
게임 UI보다 높은 정렬 순서를 갖는다.

생성 요소는 다음과 같다.

- 화면 전체를 덮는 검정 `Image`
- 중앙의 `이번에도 틀렸나...` 문구
- 문구 아래의 `타이틀화면으로 돌아가기` 버튼
- 그 아래의 `처음부터 다시하기` 버튼

초기에는 검정 오버레이의 알파가 0이고 문구와 버튼은 숨겨져 있다. 페이드가
끝났을 때만 문구와 버튼을 표시한다. 클릭 입력을 받을 수 있도록 필요한 경우
`EventSystem`과 입력 모듈을 한 번만 생성한다.

### 연결 지점

`Stage1PlayerHealthSetup.Create`가 체력 UI를 만드는 시점에 사망 화면도 함께
생성하고 `PlayerHealth` 및 플레이어 오브젝트를 연결한다. 따라서
`PlayerFactory`로 만들어지는 현재 스테이지 플레이어가 별도 씬 수작업 없이
동일한 사망 동작을 갖는다.

## 예외 및 상태 복원

- 사망 이벤트가 중복 발생해도 페이드 코루틴은 한 번만 실행한다.
- 씬 전환 버튼을 연속 클릭해도 전환 처리는 한 번만 실행한다.
- 사망 화면이 사망 처리 도중 파괴되면 `Time.timeScale`을 1로 복원해 에디터와
  다음 씬이 정지 상태로 남지 않게 한다.
- 현재 활성 씬이 유효하지 않은 테스트 환경에서는 재시작 요청을 무시하고
  오류를 발생시키지 않는다.

## 테스트

- 치명적 피해가 체력을 0으로 제한하고 `Died`를 정확히 한 번 발생시키는지
  검증한다.
- 사망 화면 생성 시 전체 화면 오버레이, 정확한 문구, 두 버튼과 캔버스 설정이
  구성되는지 검증한다.
- 사망 직후 플레이어가 숨겨지고 `Time.timeScale`이 0이 되며 메뉴는 아직
  숨겨져 있는지 검증한다.
- 실시간 1초의 페이드 뒤 검정 오버레이가 불투명하고 문구와 버튼이 표시되는지
  검증한다.
- 타이틀 버튼과 재시작 버튼이 올바른 씬 경로를 선택하고 전환 전에
  `Time.timeScale`을 1로 복원하는지 검증한다.
- 기존 체력 바와 스테이지 생성 테스트를 함께 실행해 회귀가 없는지 확인한다.
