## 1. Music Identity

### 세 단어

**그립다 · 손으로 만든 · 자란다**

### 이 사운드트랙이 유일한 이유

플레이어는 **자기 무기를 직접 그린다.** 이 게임의 정서는 전투가 아니라 그 행위에서 나온다.
따라서 음악의 과제는 "멋있는 전투곡"이 아니라 —

> **수업 시간 공책 여백에 낙서하던 그 시간으로 데려다 놓고,
> 그 낙서가 일어나 옆에서 같이 싸우게 하는 것.**

노스탤지어가 뼈대(중심), 동행이 살(보조)이다. 순서가 바뀌면 안 된다.
먼저 혼자여야 한다. 그래야 옆에 뭔가 서는 게 사건이 된다.

### 레퍼런스

| 게임 | 무엇을 가져오는가 | 무엇을 가져오지 **않는가** |
|---|---|---|
| *To the Moon* | 단 하나의 선율로 전부 버티는 절제 | 피아노 독주 위주의 정적인 편성 |
| *Undertale* | 같은 모티프를 상황마다 다시 쓰는 규율 | 장르를 매번 갈아타는 산만함 |
| *Gris* | 소리가 서서히 쌓이며 세계가 열리는 감각 | 추상적이고 가사 없는 보컬 |
| *Stardew Valley* | 손 냄새 나는 소편성, 반복을 견디는 루프 | 목가적 안온함 (이 게임엔 전투가 있다) |

### 하지 않을 것 (금지)

- **새 멜로디를 곡마다 새로 쓰는 것** — 이 사운드트랙에 곡은 4개지만 노래는 **하나**다
- **오케스트라 흉내** — 브라스 팡파레, 스트링 섹션, 합창. 이 게임은 그렇게 큰 게임이 아니고, 커 보이려 하면 손그림 아트와 싸운다
- **에픽 트레일러 문법** — 브레이크다운, 빌드업, 드롭
- **재즈 화성, 반음계 범벅** — 아이가 흥얼거릴 수 있어야 한다
- **감정 없는 전투 루프** — 보스전조차 메인 멜로디를 버리지 않는다
- **슬픔으로 도망가기** — 목표는 "슬프다"가 아니라 **"뭉클하다"** 다. 슬픔은 쉽고 뭉클함은 어렵다. 단조로 도망치지 않는다

## 2. Main Theme — 「여백」

### 핵심 모티프

플레이어가 게임을 끄고 나서 흥얼거릴 **단 하나의 선율**이다. 4곡 전부 이것으로 만들어진다.

```
A구 · 되뇜 (공책 여백에서 펜이 맴돈다 — 맴돌되 한 계단씩 오른다)
 마디1-2 축=솔  │ 솔  파  솔 · 시♭ 솔  파 │ 솔  파  솔 · 시♭ ―  ― │
                │ G4  F4  G4 · Bb4 G4  F4 │ G4  F4  G4 · Bb4 ―  ― │
 마디3   축=라♭ │ 라♭ 솔 라♭ · 도  라♭ 솔 │                        │
                │ Ab4 G4  Ab4 · C5  Ab4 G4 │                        │
 마디4   축=시♭ │ 도  시♭ 도 · 레  ―  ―  │                        │
                │ C5  Bb4 C5 · D5  ―  ―  │                        │

B구 · 상행 (낙서가 일어선다)                     ← 이 게임의 서명
 마디5 │ 시♭ 도  레 · 미♭ 파  솔 │  마디6 │ 솔 ― ― · 파 미♭ 도 │
       │ Bb4 C5  D5 · Eb5 F5  G5 │        │ G5 ― ― · F5 Eb5 C5 │
         └───── 여섯 걸음 ─────┘            └ 정점에 머문다
```

기본 조성 **E♭ 장조**, 박자 **6/8**, 음역 **E♭4–B♭5**.
**최대 음정은 완전4도.** 그보다 큰 움직임이 이 곡에는 없다.

### 이 모티프가 하는 일

| 구간 | 음악적 사실 | 게임의 의미 |
|---|---|---|
| **A구** | 같은 모양(아래 이웃 → 3도 위)이 축을 **솔 → 라♭ → 시♭**으로 한 계단씩 올린다 | 아무 일도 없는 시간. 여백. 다만 조금씩 차오른다 |
| **B구 상행** | 시♭–도–레–미♭–파–솔, **여섯 음을 걸어 올라가** 정점에 머문다 | 낙서가 일어선다 |
| **하행** | 파–미♭–도로 걸어 내려와 집으로 | 그것이 내 옆에 선다 |

**정점에 도약하지 않고 걸어 올라가는 것이 이 게임의 서명이다.**
튀어오르는 그림이 아니라 **일어서는 그림**이다. 다른 건 다 바뀌어도 이건 안 바뀐다.

### 축(axis)이 화음을 정한다 — 이 테마의 작동 원리

각 마디의 되뇜이 **그 마디 화음의 근음을 축으로 삼는다.** 이게 이 테마의 핵심 장치다.

```
마디1  축 솔  → E♭ 의 3음     마디3  축 라♭ → A♭ 의 근음
마디2  축 솔  → Gm 의 근음     마디4  축 시♭ → B♭ 의 근음
```

**축이 없으면 그 화음으로 안 들린다.** 초기 안에서 마디3의 멜로디에 시♭이 한 음도 없었는데,
베이스로 아무리 B♭을 눌러도 귀는 Dm으로 들었다(실측: 시♭이 최강 성분보다 8.5dB 아래).
축을 그 화음의 근음으로 바꾸자 시♭이 최강 성분이 됐다. **화음은 멜로디가 정한다.**

### 즉시 알아들어야 하는가 — **그렇다**

플레이어는 타이틀에서 이 선율을 방해 없이 통째로 듣는다.
그 뒤 어느 곡에서 들어도 **"아, 그 노래다"** 가 되어야 한다. 이게 설계의 전부다.

### 모든 스테이지가 재사용하는가 — **그렇다. 예외 없다**

4곡 전부 이 모티프로 만들어진다. 보스전도 마찬가지다 — **다르게 다룰 뿐, 다른 노래가 아니다.**

## 3. Stage List

### 3-1. `title.ogg` — 타이틀

| 항목 | 값 |
|---|---|
| 목적 | 메인 테마 원본을 **방해 없이** 각인시킨다. 이 곡의 성패에 나머지 3곡이 달렸다 |
| 감정 | 그리움. 오래 안 열어본 서랍 |
| 긴장 | **0 / 10** |
| 색 | 바랜 미색 — 누렇게 뜬 공책 종이 |
| 환경 | 정지된 화면. 아무 일도 일어나지 않는다 |
| 게임플레이 강도 | 없음 (버튼 한 번) |
| 예상 체류 | 10–30초 |
| 루프 길이 | **32초** (16마디) — 단 **앞 8마디(16초)만 들어도 완결**되게 쓴다 |
| BPM | **점4분음표 = 60** |
| 조 | **E♭ 장조** |
| 주 악기 | 뮤직박스 (모티프를 혼자 연주한다) |
| 보조 악기 | 뜯는 현 — **마지막 4마디에서만** 합류. 동행의 예고 |
| 타악 | **없음** |
| 레퍼런스 | *To the Moon* 「For River」의 절제, *Gris* 오프닝의 여백 |

> **이 곡의 규칙**: 16마디 중 12마디는 악기가 **하나뿐**이다. 외롭게 시작해야 한다.
> 뜯는 현이 들어오는 13마디째가 이 게임의 논지 전체다.

### 3-2. `stage1.ogg` — Stage1 야외

| 항목 | 값 |
|---|---|
| 목적 | 무기를 처음 써 보는 곳. 음악이 **"둘이 걷는 느낌"** 을 만든다 |
| 감정 | 따뜻한 모험. 겁나지 않는다 |
| 긴장 | **3 / 10** |
| 색 | 초록과 햇빛 |
| 환경 | 야외 지면, 게 적, 트인 시야 |
| 게임플레이 강도 | 낮음–중간. 이동·대시·기본 전투 |
| 예상 체류 | 2–4분 |
| 루프 길이 | **69초** (48마디) → 체류 중 2–3.5회 반복 |
| BPM | **점4분음표 = 84** (걷는 속도) |
| 조 | **E♭ 장조** (타이틀과 같음 — 같은 세계다) |
| 주 악기 | 뜯는 현이 멜로디를 **넘겨받는다**. 뮤직박스는 뒤로 물러나 장식 |
| 보조 악기 | 부드러운 패드 (얇게), 뮤직박스 대구 |
| 타악 | 셰이커 + 가벼운 킥. 6/8의 흔들림을 타되 밀어붙이지 않는다 |
| 레퍼런스 | *Stardew Valley* 봄, *Ori* 초반 숲의 부유감 |

> **이 곡의 규칙**: 멜로디 주인이 뮤직박스 → 뜯는 현으로 **바뀌는 것**이 핵심이다.
> 타이틀에서 곁에 서기만 했던 것이 여기선 앞장선다.

### 3-3. `dungeon.ogg` — 던전

| 항목 | 값 |
|---|---|
| 목적 | 조인다. 단 **겁주지 않는다** — 여긴 공포 게임이 아니다 |
| 감정 | 경계. 혼자 있는 것 같은 기분 |
| 긴장 | **6 / 10** |
| 색 | 청회색, 차가운 돌 |
| 환경 | 실내, 좁은 시야, 원거리 다람쥐 적, 투사체 |
| 게임플레이 강도 | 중간–높음. 회피 중심 |
| 예상 체류 | 3–5분 |
| 루프 길이 | **96초** (64마디) → 체류 중 1.9–3.1회 반복 |
| BPM | **점4분음표 = 80** — 네 곡 중 가장 느리다 |
| 조 | **C 단조** (E♭ 장조의 나란한조 — *같은 음들, 무게중심만 옮김*) |
| 주 악기 | 낮은 펄스(칩튠 삼각파)가 되뇜을 맡는다 |
| 보조 악기 | 패드, **파편화된 뮤직박스** — 모티프를 통째로 안 불고 조각만 흘린다 |
| 타악 | 킥 + 림. 건조하게. 리버브 최소 |
| 레퍼런스 | *Hollow Knight* 「Crossroads」의 조심스러움, *Undertale* 「Waterfall」의 고독 |

> **이 곡의 규칙**: **상행(B구)을 끝까지 미룬다.** 되뇜만 계속 돌다가,
> 루프 후반 단 한 번 정점이 나온다. 미뤄진 정점이 던전의 긴장 그 자체다.
>
> **반복을 견디게 하는 것이 이 곡의 최대 과제다.** 되뇜 하나로 96초를 버텨야 하므로
> 진술(8마디)마다 **진행·모양·악기·음역·타악을 전부 바꾼다.** 벨로시티만 바꾸면 지겹다.
> 진행 4종(P1·P2·P3·PR)을 돌리고, 멜로디 주인을 낮은 펄스 → 뮤직박스 → 뜯는 현으로
> 넘기고, **29–32마디는 통째로 비운다.** 정적도 편성의 하나다.
> 나란한조를 쓰는 이유 — 조표가 같아서 **플레이어가 조가 바뀐 걸 눈치채지 못한 채 불안해진다.**

### 3-4. `boss.ogg` — 로봇 보스

| 항목 | 값 |
|---|---|
| 목적 | 같은 노래를 **뒤집어서** 돌려준다. 새 곡이 아니라 배신당한 자장가 |
| 감정 | 다급함. 그러나 밑바닥에 그리움이 남아 있다 |
| 긴장 | **9 / 10** |
| 색 | 붉게 달군 쇠 |
| 환경 | 폐쇄된 아레나, 로봇 보스 |
| 게임플레이 강도 | 최고. 대시 회피 연속 |
| 예상 체류 | 1–2분 |
| 루프 길이 | **56초** (64마디) → 체류 중 1–2회 반복 |
| BPM | **점4분음표 = 138** (같은 음, 질주로) |
| 조 | **E♭ 단조** (평행단조 — *으뜸음이 같아서 같은 노래임이 즉시 들린다*) |
| 주 악기 | 칩튠 리드(구형파)가 멜로디를 **빼앗아 간다** |
| 보조 악기 | 낮은 톱니파 베이스, 패드는 두껍게 |
| 타악 | 풀 세트 — 킥·스네어·노이즈 하이햇. 6/8을 밀어붙인다 |
| 레퍼런스 | *Undertale* 「Megalovania」의 *모티프 재활용 방식만* (음악 자체는 아님), *Shovel Knight* 보스전의 추진력 |

> **이 곡의 규칙**: B구는 **상행 3번 + 매듭 1번**이다(29–36마디).
> 같은 오르내림을 네 번 반복하면 매듭이 없어 공회전으로 들린다. 그래서 상행은
> 세 번까지만 하고, 셋째는 정점에서 안 내려오고 한 마디를 버틴다.
> 그리고 **세 번 올라갔으니 매듭은 내려와서 짓는다** — 상행과 같은 여섯 음을
> 거울처럼 되짚어 내려와 으뜸음에 앉고, 화성이 `D♭ → E♭m`으로 닫는다.
>
> 착지를 낮게(미♭4) 잡은 이유가 하나 더 있다. 다음 구간이 솔♭4에서 시작하므로
> **3도 차이로 그대로 이어진다.** 높은 데서 끊고 뛰어내리지 않는다.
> 그리고 **아치가 닫히지 않는다** — 집으로 내려와야 할 자리에서 으뜸화음을 타고 계속 위로 오른다.
> 해결은 보스를 죽여야만 온다. 음악이 플레이어에게 빚을 지운다.

## 4. Music Structure

```
title      E♭ 장조  dq=60    A       ← 원본. 여기서 노래가 태어난다
stage1     E♭ 장조  dq=84    A'      ← 같은 조, 편성만 자란다
dungeon    C 단조   dq=80    B       ← 나란한조. 조표가 같아 몰래 어두워진다
boss       E♭ 단조  dq=138   A minor ← 평행단조. 같은 노래임을 숨기지 않는다
```

**두 축을 동시에 움직인다.**

```
템포 축   자장가 ─────────────────────────────► 질주
          60        80        84         138
          title     dungeon   stage1     boss
                    └ 던전이 stage1보다 **느리다.** 긴장을 속도가 아니라 무게로 만든다

조성 축   집 ────────────► 낯섦 ────────────► 뒤집힘
          E♭ 장조           C 단조            E♭ 단조
          (밝음)         (몰래 어두움)      (드러내고 어두움)
```

**나란한조(C단조)를 던전에, 평행단조(E♭단조)를 보스에 놓는 순서가 핵심이다.**
던전은 *조표가 같아서* 플레이어가 어두워진 걸 의식하지 못한 채 불안해진다.
보스는 *으뜸음이 같아서* 같은 노래라는 걸 즉시 알아챈다.
**숨겼다가 드러낸다.** 순서를 바꾸면 효과가 사라진다.

### 왜 E♭ 장조인가

**평균율에서 조성 자체에는 성격이 없다.** E♭ 장조와 F 장조는 음정 구조가 완전히 같고,
통째로 옮긴 것뿐이다. "E♭은 따뜻하다" 같은 말은 현대 조율에서 근거가 없다
(그 통념은 평균율 이전 조율법에서 조마다 음정 크기가 실제로 달랐던 데서 왔다).
우리 악기는 전부 합성음이라 개방현 공명 같은 물리적 조성 차이도 없다.

그래도 E♭를 고른 이유는 하나뿐이다 — **더 낮아서 어둡다.**
F 장조 대비 스펙트럼 무게중심이 **-13.1%** 내려간다(실측). 조 이름이 아니라 음높이가
한 일이다. 더 어둡게 하고 싶으면 조를 더 내리는 것보다 **멜로디 옥타브를 내리는 편이
두 배 가까이 강하다**(-22.9%).

## 5. Motif Rules

### 모티프 개수 — **1개. 끝.**

「여백」 하나뿐이다. A구(되뇜)와 B구(상행)는 별개 모티프가 아니라 **한 모티프의 두 부분**이다.

### 변형 방법 — 허용 목록 (이 밖은 금지)

| # | 조작 | 허용 |
|---|---|---|
| 1 | 템포 변경 | ✅ 주 확장 수단 |
| 2 | 조성 변경 (장↔단, 나란한조·평행조) | ✅ |
| 3 | 편성 변경 — 누가 멜로디를 부르는가 | ✅ 주 확장 수단 |
| 4 | 리듬 하위분할 밀도 | ✅ |
| 5 | 조각내기 — A구만, 상행만 떼어 쓰기 | ✅ |
| 6 | 상행 반복 / 아치 안 닫기 | ✅ 보스 전용 |
| 7 | **음정 자체 바꾸기** | ❌ **금지** |
| 8 | **B구 상행을 도약으로 바꾸기** | ❌ **절대 금지** — 걸어 올라가는 것이 서명이다 |
| 9 | **되뇜의 축을 화음 근음에서 떼기** | ❌ **금지** — 화음이 안 들리게 된다 |

> 6/8을 고른 유일한 이유가 이것이다. **음을 하나도 안 바꾸고 템포만 올려서
> 자장가를 추격전으로 만들 수 있는 박자**이기 때문이다. 그러니 음을 바꾸지 마라.

### 새 모티프는 언제 나올 수 있는가 — **이 4곡에서는 안 나온다**

던전의 C구(대비 구간)조차 새 선율이 아니라 **A구의 역행/조각**이다.
새 모티프는 이 문서 밖의 곡(추가 층, 엔딩)에서만 논의한다.

## 6. Harmony Rules

### 화음 복잡도

- **3화음이 기본.** 7화음은 감정 정점 **한 곡에 1–2회**만
- 9화음 이상 **금지**, 텐션 노트 **금지**

### 8마디 진행 — 왕도진행 + ♭VII

```
마디      1     2     3     4     5     6     7     8
장조   │ E♭ │ Gm  │ A♭ │ B♭ │ Gm │ Cm  │ D♭ │ E♭ │   title · stage1
       │ I  │ iii │ IV │ V  │iii │ vi  │♭VII│ I  │
                     └──── 왕도진행 ────┘  └ 뭉클함은 여기서만

나란한 │ Cm │ Cm  │ Fm │ B♭ │ Gm │ Cm  │ Fm │ Cm │   dungeon
평행단 │E♭m │E♭m  │A♭m │ D♭ │ G♭ │ A♭m │ D♭ │E♭m │   boss
```

**마디 3–6이 왕도진행(IV–V–iii–vi)이다.** 순서를 IV–V–iii–vi로 배치했고,
그 앞뒤를 I과 ♭VII–I이 감싼다. 머니코드의 추진력과 「여백」의 아릿함을 한 진행에 담는다.

### 「뭉클함」은 마디 7에서만 나온다

| 화음 | E♭ 장조에서 | 성격 | 사용 |
|---|---|---|---|
| **♭VII** | D♭ 장3화음 | 밝은데 아릿하다. 집에 가기 직전의 한숨 | 마디 7. **8마디에 1번** |

D♭은 E♭ 장조에 없는 음(레♭)을 들여온다 — 그 한 마디만 순간적으로 **E♭ 믹솔리디안**이 된다.
남발하면 죽는다. 다른 자리에 쓰지 않는다.

> 주의 — **단조에서는 D♭이 차용화음이 아니다.** E♭ 단조에서 D♭은 그냥 음계 안의 ♭VII다.
> 즉 이 아릿함은 **장조 전용 장치**다. 보스가 어두운 이유는 D♭ 때문이 아니라 조성 자체다.

### 진행은 멜로디가 정한다

각 마디의 되뇜 축이 그 화음의 근음(또는 3음)이 되도록 짰다. 순서가 반대다 —
**화음을 먼저 정하고 멜로디를 얹으면 안 된다.** 축이 안 맞으면 그 화음으로 안 들린다.

### 전조

- `title`, `stage1` — **전조 없음.** 집은 흔들리지 않는다
- `dungeon` — C 단조 고정. 루프 후반 상행에서 **E♭ 장조를 한 번 스친다** (기억이 스치듯)
- `boss` — E♭ 단조 고정. **전조 금지.** 도망갈 곳을 주지 않는다

### 스케일

- 장조 구간: **E♭ 이오니안** (+ ♭VII 차용 시 순간적으로 믹솔리디안)
- 단조 구간: **자연단음계.** 3·6·7음을 **전부** 내린다 — 7음을 안 내리면 화성단음계가 되어
  6·7음 사이에 증2도가 생긴다. 그 소리는 **금지**다(이국적으로 들려 정서가 어긋난다)

### 재즈? — **금지.** 반음계? — **경과음으로만.** 화음 구성음에 반음계 금지

## 9. Instrument Rules

> 감독 결정에 따라 산출물은 **MIDI + 자작 신디사이저 렌더**다.
> 팔레트는 그 제약 안에서 정직하게 좋은 소리가 나는 것만 고른다.

### 팔레트 (이 6개가 전부)

| # | 악기 | 합성 방식 | 역할 | 정서 |
|---|---|---|---|---|
| 1 | **뮤직박스 / 벨** | FM 합성 | 노스탤지어의 핵 | 어린 시절 그 자체 |
| 2 | **뜯는 현** (하프·기타) | Karplus-Strong | **동행** — 내가 그린 것 | 곁에 선 것 |
| 3 | **부드러운 패드** | 필터 걸린 삼각/톱니 | 공간, 세계 | 배경의 공기 |
| 4 | **칩튠 리드** (구형파) | 펄스파 | 전투 에너지, "게임"의 정체성 | 옛날 게임기 |
| 5 | **베이스** | 삼각/톱니 저역 | 무게 | 땅 |
| 6 | **타악** | 노이즈 + 사인 | 추진력 | 심박 |

### 금지 악기

- **오케스트라 브라스·스트링 섹션, 합창** — 자작 신스로는 티가 나고, 정서적으로도 이 게임보다 크다
- **사실적 관악 솔로** (플루트·오보에) — 흉내가 가장 안 되는 영역
- **샘플 드럼킷, 어쿠스틱 피아노** — 위와 같은 이유
- **보컬 일체**

### 편성이 자라는 법 — 이게 「동행」이다

```
title     뮤직박스 ─ 혼자 (12마디)
              └─ + 뜯는 현 (마지막 4마디)     ← 무언가 곁에 선다

stage1    뜯는 현 [멜로디] + 뮤직박스 [장식] + 패드 + 셰이커/킥
              └─ 곁에 섰던 것이 앞장선다

dungeon   낮은 펄스 [되뇜] + 패드 + 뮤직박스 [조각] + 킥/림
              └─ 편성이 흩어진다. 동행이 멀어진다

boss      칩튠 리드 [멜로디 탈취] + 톱니 베이스 + 두꺼운 패드 + 풀 드럼
              └─ 노래가 적의 손에 넘어갔다
```

**악기 배분 자체가 서사다.** 뮤직박스가 사라져가고 칩튠이 멜로디를 빼앗는 것이
「혼자였다 → 동행이 생겼다 → 멀어졌다 → 빼앗겼다」를 말한다. 가사 없이.

### 트랙 수 상한

곡당 **최대 6트랙.** 넘어가면 손그림의 소박함과 싸운다.

## 10. Dynamic Curve

### 한 루프 안의 긴장 곡선

```
A ── 되뇜. 악기 최소. 아무 일도 없다
↓
A' ─ 같은 되뇜에 악기 하나 추가. 뭔가 다가온다
↓
B ── 상행. 곡의 정점. 편성 최대
↓
A'' ─ 되뇜으로 돌아온다. 단 처음과 같지 않다 — 무언가 남는다
```

**A''는 A로의 복귀가 아니다.** 겪고 돌아온 자리다. 악기 하나가 더 남아 있거나,
화음 하나가 달라져 있다. 그래야 루프가 원이 아니라 **나선**이 된다.

### 곡별 배분

| 곡 | 총 마디 | A | A' | B | A'' | 비고 |
|---|---|---|---|---|---|---|
| `title` | 16 | 4 | 4 | 4 | 4 | 앞 8마디만 들어도 완결 |
| `stage1` | 48 | 8 | 8 | 16 | 16 | B가 가장 넓고 가장 두껍다 — 여기가 걷는 즐거움 |
| `dungeon` | 64 | 8 | 8 | 16 | 16 | **+ C구 16마디**(B와 A'' 사이). **상행을 A''까지 미룬다** |
| `boss` | 64 | 8 | 8 | 16 | 16 | **+ 도입 4 · 테마 3회차 8 · 꼬리 4.** A''에서 아치를 안 닫는다 |

**C구는 던전에만 있다.** 그리고 새 선율이 아니라 **A구를 거꾸로 읽은 것**이다(5절이 새 모티프를 금지한다).
보스의 테마 진술은 8마디 단위라 12마디로 쪼개지지 않는다 — 도입 4 + 8마디 진술 3회 + B 16 + A'' 16 + 꼬리 4 = 64.

### 곡별 정점의 성격

- `title` — 정점이 **작다.** 상행 한 번, 뜯는 현 합류. 그게 다다
- `stage1` — 정점이 **넓다.** 오래 머문다. 즐거운 곳이다
- `dungeon` — 정점이 **늦다.** 기다림 자체가 긴장이다
- `boss` — 정점이 **안 끝난다.** 해결은 보스를 죽여야 온다

## 11. Production Rules

### 산출물 — **MIDI + OGG 둘 다** (감독 결정)

| 산출물 | 경로 | 크기 | 용도 |
|---|---|---|---|
| `*.mid` | `Assets/Audio/Bgm/midi~/` | 23KB | **악보 원본.** 나중에 좋은 음원으로 다시 렌더 가능 |
| `*.wav` | `Assets/Audio/Bgm/wav~/` | 42MB | **무압축 음원.** vorbis 손실 없는 원본 |
| `*.ogg` | `Assets/Audio/Bgm/` | 4.7MB | 게임에 실제로 들어가는 버전 |
| `*.ogg.meta` | `Assets/Audio/Bgm/` | — | 임포트 설정. 기본값으로 들어가면 사고가 난다 |

**버리는 작업이 없다.** 음질을 올리고 싶어지면 MIDI만 DAW에 넣으면 된다.
WAV는 `.ogg`를 만들기 **직전의 그 렌더 그대로**다 — 디코드한 것이 아니라 무손실 원본이다.

폴더가 `midi~` `wav~`인 이유 — 유니티는 `~`로 끝나는 폴더를 통째로 무시한다.
MIDI는 임포터가 없어 에셋 목록만 더럽히고, **WAV는 40MB가 넘어 그냥 두면 같은 음악이
빌드에 두 번 실린다.** `Assets/Audio/unfixed~/`와 같은 규칙이다.

### 다시 만들기

```bash
python3 tools/bgm/build.py      # 4곡 전부 (~20초)
```

곡은 코드로 정의돼 있다. 멜로디를 고치려면 [`tools/bgm/theme.py`](../../../tools/bgm/theme.py)
한 곳만 고치면 4곡이 같이 바뀐다 — 그게 "노래는 하나"라는 규칙을 코드로 강제한 것이다.

| 파일 | 역할 |
|---|---|
| `tools/bgm/theme.py` | **메인 테마 원본.** 모티프·조성·화성 진행 |
| `tools/bgm/songs.py` | 4곡의 편곡 (3·4·10절) |
| `tools/bgm/synth.py` | 자작 신디사이저 (9절 팔레트) |
| `tools/bgm/midiout.py` | MIDI 라이터 |
| `tools/bgm/build.py` | 렌더 · 루프 되접기 · 음량 정렬 · `.meta` 생성 |

### MIDI 규격

- Format 1 (멀티트랙), 480 ticks/quarter
- **트랙당 악기 1개**, 트랙 이름은 팔레트 이름 그대로
- 벨로시티를 실제로 쓴다 — 전부 100으로 채우지 않는다
- 6/8 박자표와 템포를 메타 이벤트로 명시

### 렌더 체인

```
Python 자작 신디사이저 (numpy) → 44.1kHz 스테레오 WAV → ffmpeg → OGG (Vorbis)
```

이 환경에는 `fluidsynth`·`timidity`·사운드폰트가 **없다.** `ffmpeg`와 `numpy`는 **있다.**
9번 팔레트는 이 제약을 전제로 고른 것이다 — 자작 신스가 실제로 잘 내는 소리들이다.

### 파일 이름 — [../README.md](../README.md) 규칙 준수

```
title.ogg   stage1.ogg   dungeon.ogg   boss.ogg
```

소문자 영어와 밑줄만. 확장자 `.ogg`.

### Unity 임포트 설정 — **효과음과 정반대다**

| 항목 | 값 |
|---|---|
| Load Type | **Streaming** ← 이걸 틀리면 수십 MB가 메모리에 올라간다 |
| Force To Mono | **끔** |
| Sample Rate | 44100Hz (원본 유지) |
| Compression | Vorbis |
| Normalize | **끔** ← 켜면 유니티가 곡마다 다시 정규화해서 아래 음량 정렬이 깨진다 |

`build.py`가 `.ogg.meta`를 위 설정으로 직접 써 두므로 유니티에서 손댈 것이 없다.
**GUID는 이미 있으면 그대로 지킨다** — 다시 빌드해도 씬 참조가 끊기지 않는다.

### 음량 — 피크가 아니라 RMS로 맞춘다

4곡의 **RMS를 -14.5dBFS로 정렬**하고 피크는 0.80으로 제한한다.

씬이 바뀔 때 볼륨이 튀거나 꺼지면 곡이 아무리 좋아도 "소리가 이상한 게임"이 된다.
피크 정규화로는 이걸 못 맞춘다 — 던전처럼 조용하게 시작하는 곡은 피크가 같아도
체감 음량이 3dB 넘게 낮다. 실제로 첫 렌더에서 던전만 -16.5dB로 혼자 꺼져 있었다.

피크 한도가 0.80인 이유도 실측이다. **Vorbis는 표본 사이에서 튄다** — WAV에서 0.94로
맞춘 것이 디코드하면 1.02가 되어 클리핑됐다. 인코딩 오버슛만큼 미리 비워 둔다.

BGM은 효과음 밑에 깔리는 소리다. 꽉 채우지 않는다.

### 루프 이음매

- 마지막 마디가 첫 마디로 **끊김 없이** 이어져야 한다
- **리버브 꼬리를 잘라 두지 않는다** — 루프 끝의 잔향을 곡 앞머리에 겹쳐 넣는다
- 루프 지점에서 파형이 0을 지나게 맞춘다 (클릭 방지)

## 부록 — 승인 범위 밖의 변주판

감독 지시로 추가된 곡들. 본문 4곡의 규칙을 그대로 따르되, 예외는 아래에 명시한다.

| 곡 | 무엇 | 본문과 다른 것 |
|---|---|---|
| `dungeon_major` `boss_major` | 장조판 | 조성만 E♭ 장조. 편곡 동일 |
| `boss_p1` | 보스 1페이즈 · **재즈** | **리듬·화성은 boss_major 그대로, 선율만 새로 썼다** — 규칙 7의 명시적 예외(여기 한정). 시♭ 축 맴돌기 + 9음, 정점이 낮다(미♭5). 점4분 116, 라이드 스윙 + 워킹 베이스, 컴핑 마디당 1번, 멜로디는 뜯는 현. **7화음 허용** — 6절의 문을 여기서만 연다 |
| `boss_p2` | 보스 2페이즈 · **락** | 같은 원리의 락 선율 — 5음(시♭)을 반복해 두들기고 4·5도로 뛴다(펜타토닉). 정점은 원곡처럼 솔5, **끝은 올라가며 닫는다.** 칩튠이 부르고, 드라이브 기타 파워코드(3음 없음 — 디스토션 배음 충돌 방지)·오버드라이브 베이스·백비트. **팔레트 예외** — 9절의 문을 여기서만 연다 |
| `field` | 필드 · **감독 스케치 멜로디** | 감독이 로직으로 쓴 플루트 선율이 원본(`midi~/field_sketch.mid` 보존). 「여백」 밖의 첫 멜로디 — 머리말이 "그 외 층"을 처음부터 범위 밖에 두었다. **G 단조 · 4/4 · 4분=126 · 48마디(91초).** 초원 사냥터의 활기가 목표다. 필드 BGM 관례대로 벌스-후렴 두 회전: **인트로4 · A8 · A′8 · B8 · A″8 · B′8 · 꼬리4.** 벌스(A)는 스케치 그대로(착지음 하나만 늘림) — 단조 아르페지오 모티프(1·♭7·1·♭3·5)가 Dm→Cm→B♭m으로 온음씩 내려앉고 G에 앉는다. 후렴(B)은 그 모티프의 **장조 반전**(1·7·1·3·5) — 같은 손모양이 B♭ 장조 I–V–vi–IV 위를 올라간다. 내려앉던 노래가 후렴에서 일어선다. 악기 서사: 벌스는 뜯는 현(한 옥타브 아래 — 플루트 음역은 9절 관악 금지), 후렴은 칩튠이 분다 — **경계하다, 달려든다.** 뮤직박스는 인트로 예고·A″ 원음역 유니즌·B′ 옥타브 반짝임. 벌스는 근·근·5·근 뛰는 베이스+림, 후렴은 8분음표 베이스+스네어 백비트+크래시. 꼬리 F(V)가 루프 첫 마디 Gm을 끌어당긴다. 4/4라서 이 곡만 `meter` 필드를 쓴다 |

| `intro` | 전주 (18.5초, 한 번짜리) | **루프하지 않는다.** 되뇜의 축 4개(솔→시♭→라♭→도)를 슬로모션으로 놓고, 상행을 **다섯 걸음까지만** 인용하고 멈춘다 — 정점은 본 곡이 완성한다. 마디 7 ♭VII, **B♭(V) 반종지**로 끝나 본 곡의 E♭이 '도착'이 된다 |
| `title_intro` | 전주+타이틀 결합판 | 위 전주 8마디 + 타이틀 16마디, 한 파일 |
| `boss_intro` | 단조 전주+보스 결합판 | 같은 전주를 단조·2배 길이(16마디)로. 심장박동 킥이 다가오다 보스의 원래 드럼 도입이 다리가 된다 |

구조(A×3 → B 상행3+매듭 → A'' 아치 안 닫힘)·리듬·화성은 boss_major와 완전히 같고,
**선율만 다르다.** 같은 걸음걸이로 다른 노래를 부르는 형제 곡이다 — 원곡과 나란히 들으면
리듬이 같다는 것이 들린다. 악기 서사는 이어진다: 1페이즈는 뜯는 현(동행)이 부르고,
2페이즈에서 칩튠이 빼앗는다.

기타·베이스 디스토션은 흉내가 아니라 원리 그대로다 — 디스토션은 파형을 찌그러뜨리는
것이므로(`tanh`), 신스로 만들 수 있다. 캐비닛(고역 감쇠)까지 거쳐야 톱밥 소리가 안 난다.
