# 무기 효과음 파일명 규칙

무기는 플레이어가 그린 그림으로 만들어지므로 종류가 무한하다. 무기 하나에 소리 하나를
붙이는 방식은 성립하지 않는다. 그래서 **소리를 축으로 쪼개 조합으로 덮는다.**

```
{motion}_{weight}_{material}.ogg
```

파일명이 곧 등록이다. 별도 목록에 손으로 적는 곳은 없다 — 폴더에 넣으면 잡히고,
빼면 사라진다.

## 세 축

| 축 | 값 | 어디서 오는가 |
|---|---|---|
| `motion` | `swing` `thrust` `slam` `throw` `shoot` | `WeaponType`과 1:1 (게임이 무작위로 정한다) |
| `weight` | `light` `medium` `heavy` | `damage`·`shotsPerSecond`에서 유도 |
| `material` | `metal` `wood` `stone` `organic` `liquid` `magic` `cloth` | 백엔드가 그림을 보고 판정 (`WeaponMaterial`) |

`motion`은 **화면에서 벌어지는 동작**이다. 그림이 쇠몽둥이여도 타입이 `shoot`으로
뽑혔으면 소리도 `shoot`이어야 한다. 보이는 동작과 들리는 소리가 어긋나면
그림에 맞춘 소리보다 훨씬 어색하다.

`motion`은 마음대로 늘릴 수 없다. 새 동작을 만들려면 애니메이션과 히트박스가 따라와야
하므로 사운드만의 문제가 아니다. 반면 `material`은 소리에만 쓰이므로 자유롭게 늘려도 된다.

### `weight`는 스탯에서 계산한다

무기에 무게 필드는 없다. **한 번 휘두르는 데 실린 힘**으로 환산한다.

```
무게값 = damage × attackInterval
```

| 무게값 | 태그 |
|---|---|
| 3 미만 | `light` |
| 3 이상 10 미만 | `medium` |
| 10 이상 | `heavy` |

데미지만 보지 않는 이유는, 약하게 여러 번 때리는 무기와 세게 한 번 때리는 무기가
같은 초당 데미지를 낼 수 있기 때문이다. **묵직함은 한 방의 크기에서 온다.**

지금 샘플 무기로 계산하면 이렇게 갈린다.

| 무기 | 계산 | 태그 |
|---|---|---|
| 도끼 | 10 × 1.0 = 10 | `heavy` |
| 창 | 8 × 0.8 = 6.4 | `medium` |
| 검 | 7 × 0.6 = 4.2 | `medium` |
| 투사체 | 5 × 0.8 = 4.0 | `medium` |
| 총 | 3 × 0.2 = 0.6 | `light` |

임계값은 소리를 넣어보고 조정한다. **여기 적힌 숫자가 기준이므로 코드에서 바꾸면
이 문서도 같이 고친다.**

## `any` — 그 축을 따지지 않는다

```
any_any_liquid.ogg     물 계열이면 던지든 휘두르든 전부 이것
swing_any_metal.ogg    금속 휘두르기, 무게는 안 따짐
slam_heavy_metal.ogg   정확히 이 조합만
default.ogg            아무것도 안 맞을 때 (반드시 하나 있어야 한다)
```

**같은 소리를 두 이름으로 복사하지 마라.** 유니티가 같은 오디오를 두 번 빌드에 넣고,
나중에 한쪽만 교체하면 조용히 어긋난다. `any`를 쓰면 파일 하나가 여러 조합을 덮는다.

## 폴백 순서

위에서부터 훑어 처음 있는 것을 쓴다.

```
1. {motion}_{weight}_{material}     slam_heavy_metal
2. {motion}_any_{material}          slam_any_metal
3. any_{weight}_{material}          any_heavy_metal
4. any_any_{material}               any_any_metal
5. {motion}_{weight}_any            slam_heavy_any
6. {motion}_any_any                 slam_any_any
7. default
```

이 순서 덕분에 **어색한 조합은 파일을 안 만드는 것으로 처리된다.** 물을 내려찍는
`slam_heavy_liquid` 같은 건 만들 필요가 없다. 없으면 재질을 버리고 `slam_heavy`로 내려간다.
나중에 쓸 만한 소리를 구하면 파일만 넣으면 살아난다.

## 축마다 지배력이 다르다 — 파일 배치로 표현한다

재질에 따라 소리를 좌우하는 축이 다르다. 코드 분기 없이 **어떤 파일을 만드느냐**로 정한다.

**금속처럼 동작이 지배하는 재질**

```
swing_any_metal.ogg
thrust_any_metal.ogg
slam_any_metal.ogg
```

`any_any_metal.ogg`는 **만들지 마라.** 만들면 폴백 4번에서 걸려 동작을 무시하고
그것이 이겨버린다. 금속은 휘두르는 소리와 찌르는 소리가 확연히 다르다.

**물·슬라임처럼 재질이 지배하는 것**

```
any_any_liquid.ogg
```

하나면 된다. 던지든 휘두르든 결국 첨벙거린다.

## 채우는 순서

전 조합은 `5 × 3 × 7 = 105`개지만 다 채울 일은 없다.

| 순서 | 파일 | 개수 | 효과 |
|---|---|---|---|
| 1 | `default` | 1 | 무음 방지 |
| 2 | `{motion}_any_any` | 5 | 화면 동작과 일치 — 체감이 가장 크다 |
| 3 | 재질이 지배하는 것 (`any_any_liquid` 등) | 3~5 | 무기 개성 |
| 4 | 자주 나오는 조합만 세분화 | 필요할 때 | 완성도 |

2단계까지 6개면 어색하지 않게 돌아간다.

## 같은 조합에 여러 개를 두려면

뒤에 숫자를 붙인다. 재생할 때 그중 하나를 무작위로 고른다.

```
swing_any_metal.ogg
swing_any_metal_2.ogg
swing_any_metal_3.ogg
```

매 공격마다 같은 파일이 나오면 금방 질린다. 무기 스탯으로 피치를 흔드는 것과
함께 쓰면 파일 몇 개로도 훨씬 다양하게 들린다.

## 임포트 설정

효과음은 짧고 많다. 개수보다 **설정이 용량을 좌우한다** — 300개 기준 26MB와 1.2MB로 갈린다.

| 항목 | 값 | 이유 |
|---|---|---|
| Force To Mono | 켠다 | 2D에서 스테레오는 낭비. 정위는 AudioSource의 pan으로 |
| Sample Rate Setting | Override → 22050Hz | 0.5초짜리 타격음에서 44.1kHz와 구분이 안 간다 |
| Load Type | Decompress On Load | 재생 지연이 없다. 짧은 소리에만 |
| Compression | Vorbis | |

BGM은 설정이 정반대다. `Assets/Audio/Bgm/`에 따로 두고 절대 여기 설정을 일괄 적용하지 마라.

## 원본은 여기 두지 않는다

받아온 그대로의 파일은 `Assets/Audio/unfixed~/`에 둔다. 노멀라이징·클리핑을 거친
결과물만 이 폴더로 내보낸다.

`~`로 끝나는 폴더는 유니티가 통째로 무시하므로 원본은 빌드에 실리지 않는다.
자세한 처리 기준은 그쪽 README에 있다.

## 파일을 추가할 때

- 확장자는 `.ogg`, 44.1kHz 이상 원본에서 변환
- 어휘 밖 단어를 쓰지 마라. `superheavy` 같은 오타는 조용히 폴백으로 떨어져 알아채기 어렵다
- `.ogg.meta`가 같이 커밋되는지 확인해라. 여러 개를 한 번에 넣으면 빠뜨리기 쉽다
- 출처와 라이선스를 `LICENSES.md`에 적어라. CC-BY면 크레딧 표기 의무가 있고,
  나중에 어느 파일이 어느 라이선스였는지 되짚을 방법이 없다
