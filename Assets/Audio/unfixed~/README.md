# unfixed — 손대기 전 원본

받아온 그대로의 오디오를 둔다. 노멀라이징·클리핑·트리밍을 거친 결과물만
`Assets/Audio/`의 각 폴더로 내보낸다.

## 폴더 이름이 `unfixed~`인 이유

유니티는 **`~`로 끝나는 폴더를 애셋 파이프라인에서 통째로 무시한다.** 그래서 여기 있는
파일은 임포트되지 않고, `.meta`도 안 생기고, 빌드에도 안 들어간다.

`~`를 빼면 원본 WAV까지 전부 빌드에 실린다. 무압축 44.1kHz 스테레오는 게임에 쓰는
파일보다 15~25배 크므로, 원본 300개면 빌드가 26MB쯤 불어난다. 폴더 이름의 물결 하나가
그걸 막는다. **이름을 바꾸지 마라.**

git은 `~`를 신경 쓰지 않으므로 버전 관리는 정상적으로 된다.

## 작업 흐름

```
unfixed~/Weapon/  받아온 원본 (건드리지 않는다)
        ↓  노멀라이징 · 클리핑 · 앞뒤 무음 제거 · 파일명 규칙 적용
Assets/Audio/Weapon/  게임이 쓰는 파일
```

원본을 덮어쓰지 마라. 나중에 "조금 더 크게" 같은 요구가 생기면 원본에서 다시 뽑는 게
이미 처리된 파일을 또 건드리는 것보다 훨씬 낫다. 처리를 두 번 거치면 소리가 뭉개진다.

## 처리 기준

| 항목 | 값 | 이유 |
|---|---|---|
| 피크 노멀라이즈 | -1.0 dBFS | 0dB로 붙이면 인코딩 후 클리핑이 난다 |
| 앞뒤 무음 | 잘라낸다 | 남아 있으면 타격 순간이 밀려 둔하게 들린다 |
| 페이드 아웃 | 끝 5~10ms | 뚝 끊기면 '틱' 소리가 난다 |
| 길이 | 효과음 1초 이내 | 다음 공격과 겹치면 지저분해진다 |

파일별 볼륨 편차는 여기서 잡아야 한다. 재생 코드에서 무기마다 볼륨을 다르게 주기
시작하면 관리할 수 없다.

## 원본 파일명

**내보낼 이름 + `_unfixed`**로 둔다. 확장자는 받아온 그대로다.

```
swing_any_metal_unfixed.mp3   →   Assets/Audio/Weapon/swing_any_metal.ogg
```

받아온 이름(`683101__florianreichelt__quick-woosh.mp3` 같은 것)을 그대로 두면 원본과
내보낸 파일을 짝지을 방법이 없다. 소리는 들어보기 전에는 어느 것이 어느 것인지 모른다.
출처는 `LICENSES.md`가 파일명 기준으로 기록하므로 원본 이름에 남길 필요가 없다.

내보낼 이름을 아직 못 정했으면 그것부터 정해라. 정하는 데 필요한 건
`Assets/Audio/Weapon/NAMING.md` 하나뿐이고, 나중으로 미루면 원본이 쌓여서 더 어려워진다.

출처와 라이선스는 `Assets/Audio/LICENSES.md`에 적는다.
