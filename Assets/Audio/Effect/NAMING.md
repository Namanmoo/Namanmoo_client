# 상태이상·장판 효과음 파일명 규칙

감속, 화상, 독, 불 장판처럼 **한 번 나고 마는 게 아니라 걸려 있는 동안 계속되는** 것들.

```
{출처}_{효과}_{단계}.ogg

zone_burn_loop.ogg     불 장판이 깔려 있는 동안
self_burn_start.ogg    몸에 불이 붙는 순간
any_slow_start.ogg     감속에 걸리는 순간 (어디서 왔든)
```

## 세 축

| 축 | 값 | |
|---|---|---|
| `출처` | `self` `zone` `any` | 몸에 붙었나, 바닥에 깔렸나 |
| `효과` | `burn` `slow` `poison` `freeze` `shock` `heal` `shield` | 무엇이 걸렸나 |
| `단계` | `start` `loop` `end` | 언제 나는 소리인가 |

### 출처를 나누는 이유

**같은 불이라도 내 몸이 타는 소리와 바닥에 깔린 불의 소리는 다르다.** 몸에 붙은 불은
가깝고 다급하게 들려야 하고, 장판은 배경처럼 깔려 있어야 한다.

구분이 필요 없으면 `any`를 쓴다. 감속은 몸에 걸리든 장판을 밟았든 같은 소리여도 어색하지
않으므로 `any_slow_start` 하나면 된다.

### 단계

| | |
|---|---|
| `start` | 걸리는 순간. 한 번 재생 |
| `loop` | 걸려 있는 동안. **끊김 없이 반복** |
| `end` | 풀리는 순간. 한 번 재생 |

## 단계는 폴백하지 않는다

다른 폴더와 다른 점이다. **`loop`가 없다고 `start`를 대신 틀면 안 된다.**
반복 재생되면서 시작음이 계속 튀어 최악으로 들린다.

없는 단계는 그냥 소리가 안 난다. 화상에 `start`만 있고 `loop`가 없으면, 불이 붙을 때만
소리가 나고 타는 동안은 조용하다. **그게 맞는 동작이다.**

## 폴백 순서

출처와 효과만 폴백한다.

```
1. {출처}_{효과}_{단계}     zone_burn_loop
2. any_{효과}_{단계}        any_burn_loop
3. (없으면 무음)
```

`{출처}_any_{단계}` 같은 건 만들지 마라. "무슨 효과인지 모르겠지만 뭔가 걸린 소리"는
쓸모가 없다. 효과를 구분하지 못할 바에는 조용한 편이 낫다.

**`default.ogg`를 두지 않는다.** `Weapon/`이나 `Impact/`는 소리가 없으면 공격이 먹히는지
알 수 없어서 안전망이 필요했지만, 상태이상은 화면에 표시가 따로 있다.
아무 소리나 반복 재생되는 것이 무음보다 훨씬 나쁘다.

## 루프 파일은 다르게 다룬다

`loop`가 붙은 파일만의 규칙이다.

- **앞뒤가 이어져야 한다.** 끝과 시작이 매끄럽게 물리지 않으면 반복할 때마다 '툭' 소리가 난다
- **페이드를 넣지 마라.** 다른 효과음은 끝에 5~10ms 페이드아웃을 넣지만 루프는 안 된다.
  페이드가 이음매에서 소리를 꺼뜨린다
- **유니티 임포트에서 Loop를 켠다** (`AudioSource.loop`)
- 길이는 1~3초. 너무 짧으면 반복이 티 나고 너무 길면 메모리를 먹는다

`start` / `end`는 일반 효과음과 같다 (1초 이내, 끝에 페이드).

## 임포트 설정

| 항목 | `start` / `end` | `loop` |
|---|---|---|
| Load Type | Decompress On Load | Decompress On Load |
| Force To Mono | 켠다 | 켠다 |
| Sample Rate | Override → 22050Hz | Override → 22050Hz |
| Loop | 끈다 | **켠다** |

장판 루프가 길어지면(5초 이상) `Compressed In Memory`를 고려한다. 다만 BGM이 아니므로
`Streaming`까지는 가지 않는다 — 재생 시작이 밀린다.

## 채우는 순서

| 순서 | 파일 | 효과 |
|---|---|---|
| 1 | 쓰는 효과의 `any_{효과}_start` | 걸린 것을 알림 — 체감이 가장 크다 |
| 2 | `zone_{효과}_loop` | 장판이 깔려 있다는 감각 |
| 3 | `any_{효과}_end` | 풀린 것을 알림 |
| 4 | `self_` 로 출처 구분 | 완성도 |

**`start`가 제일 중요하다.** 걸리는 순간을 놓치면 플레이어가 왜 느려졌는지 모른다.
`loop`와 `end`는 없어도 게임이 성립한다.

## 그 밖의 규칙

`Assets/Audio/README.md`의 공통 규칙과 같다.

- 소문자 영어와 밑줄만, 확장자는 `.ogg`
- 같은 자리에 여러 개를 두려면 뒤에 숫자 (`any_burn_start_2.ogg`).
  단 `loop`는 여러 개를 두지 마라 — 바뀌는 순간이 티 난다
- 원본은 `Assets/Audio/unfixed~/Effect/`에, 출처는 `Assets/Audio/LICENSES.md`에
